# Sistema de logo

O sistema pode conter símbolo, wordmark, assinatura principal, lockup
horizontal, lockup vertical e versão compacta. Produza variantes light, dark,
monocromática e negativa somente a partir do mesmo desenho aprovado.

O SVG mestre deve possuir `viewBox`, formas vetoriais, nomes previsíveis e
cores compatíveis com os tokens. Evite filtros, máscaras frágeis, imagens
raster incorporadas e dependência de uma fonte não licenciada.

`assets/logo-source-example.svg` demonstra uma fonte composta somente por
formas. Ele serve para testar exportação e estrutura, não como conceito pronto
para uma marca.

Teste redução, reprodução em uma cor, impressão simples, fundo fotográfico,
favicon, avatar, cabeçalho e leitura distante. Documente área de proteção,
tamanho mínimo, alinhamento e usos incompatíveis.
